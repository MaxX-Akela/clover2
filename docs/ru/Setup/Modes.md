# Полетные режимы

**Режим** полета определяет алгоритм управления конструктором и реакцию полетного контроллера на команды пользователя.

Чтобы настроить полетные режимы, используйте QGroundControl:

1. Перейдите в панель *Vehicle Configuration*.
2. В левом меню выберите *Flight Modes*.
3. Установите *Mode Channel* (переключение полетных режимов) на переключатель **SwC** (*Channel 6*).
4. При необходимости установите *Emergency Kill Switch Channel* (аварийное отключение электродвигателей) на переключатель **SwA**.
5. В пунктах Flight Mode 1-6 выберите необходимые режимы для разных положений переключателя.

Рекомендуемые режимы:

* *Flight Mode 1*: **Stabilized**
* *Flight Mode 4*: **Altitude**
* *Flight Mode 6*: **Position**

Переключайте режимы с помощью назначенного переключателя и проверяйте, что QGroundControl корректно отображает выбранный режим.

## Ручное управление

В ручных режимах пилот управляет конструктором квадрокоптера напрямую. GPS, компьютерное зрение и барометр не используются. Для таких режимов нужны хорошие навыки пилотирования.

* **STABILIZED** / **MANUAL** — режим стабилизации горизонтального положения. Пилот управляет газом, наклоном по тангажу и крену, а также угловой скоростью по рысканью. Конструктор квадрокоптера самостоятельно выравнивается по крену и тангажу, если отпустить стики.
* **ACRO** — режим управления газом и угловыми скоростями. Конструктор не выполняет автоматическое выравнивание после возврата стика крена или тангажа в центральное положение. Чаще используется в гонках. Без хорошего опыта легко потерять контроль.
* **RATTITUDE** — сочетание режимов **STABILIZED** и  **ACRO**. При небольшом отклонении стика режим работает аналогично режиму **STABILIZED**. При значительном отклонении стика режим переходит к управлению, аналогичному режиму **ACRO**.

## Режимы с использованием дополнительных датчиков

* **ALTCTL** (*Altitude*) — управление скоростью изменения высоты полёта, углами по тангажу и крену и угловой скоростью по рысканью. Используется барометр (или иной датчик высоты) для удержания высоты.
* **POSCTL** (*Position*) — управление положением и скоростью движения. Использует барометр, GPS, компьютерное зрение или другие датчики. Это один из самых удобных режимов для обычных полётов.

## Автоматический полёт

В автоматических режимах дрон выполняет программу полёта и не управляется напрямую стиками пульта управления.

* **OFFBOARD** — управление полётом с внешнего компьютера, например с Raspberry Pi. Этот режим используется для автономных полётов, в том числе с применением ROS 2.
* **AUTO.MISSION** — выполнение заранее загруженной полётной миссии. Миссию можно загрузить через QGroundControl или по MAVLink.
* **AUTO.RTL** — автоматический возврат в точку взлёта: дрон поднимается (при необходимости), летит к точкеи выполняет посадку (поведение можно настроить параметрами).
* **AUTO.LAND** — автоматическая посадка в текущей точке. Полезно при потере сигнала или для безопасного завершения полёта.

Дополнительная информация: [PX4 Flight Modes](https://docs.px4.io/main/en/flight_modes/).
